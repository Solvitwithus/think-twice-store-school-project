# Think Twice - Quick Start Guide

## 🚀 Get Up and Running in 5 Minutes

### Step 1: Login
1. Navigate to `http://localhost/think-twice/`
2. If you don't have an account:
   - Click "Create one" link
   - Fill in the form with at least:
     - Full Name: Your name
     - Username: lowercase, 3+ chars
     - Email: valid email
     - Password: 8+ chars, must include uppercase, lowercase, number, and special character
   - Click "Create Account"

3. You'll be redirected to login
4. Enter your username and password
5. Click "Sign In"

### Step 2: Explore the Dashboard
After login, you'll see the **Dashboard** with:
- **Key Statistics** - Total items, stock value, suppliers, recent transactions
- **Quick Actions** - Fast links to POS, Inventory, Suppliers, Reports
- **System Info** - Your user details and permissions
- **Recent Transactions** - Latest M-Pesa sales

### Step 3: Navigate the System

#### 🛒 **Point of Sale (POS)**
```
Dashboard → Point of Sale
  └─ Scan barcode
  └─ Select payment method (Cash, M-Pesa, Split)
  └─ Process payment
  └─ Print receipt
```

#### 📦 **Inventory Management**
```
Dashboard → Inventory
  ├─ Create Item - Add new products
  ├─ Create Category - Organize items
  ├─ Goods Receive Note - Record incoming stock
  ├─ Price Setting - Manage pricing
  └─ Warehousing - Multi-location tracking
```

#### 👥 **Suppliers**
```
Dashboard → Suppliers
  ├─ Add Supplier - New supplier details
  ├─ Edit Supplier - Update information
  └─ Delete Supplier - Remove supplier
```

#### 📊 **Reports**
```
Dashboard → Reports
  ├─ Sales Report - Daily/weekly sales data
  ├─ Inventory Report - Stock levels and values
  ├─ Suppliers Report - Supplier performance
  └─ Transactions - M-Pesa transaction history
```

#### ⚙️ **Admin Panel**
```
Dashboard → Admin
  ├─ Create Role - Define new user roles
  ├─ Manage Permissions - Assign permissions
  └─ Assign Roles - Set user roles
```

## ❓ Common Tasks

### Add a New Item to Inventory
1. Go to **Inventory**
2. Click **Create New Item**
3. Fill in:
   - Item Name
   - Barcode (scan or type)
   - Category
   - Unit Price
   - Quantity in Stock
4. Click **Add Item**

### Process a Sale
1. Go to **Point of Sale**
2. Scan item barcodes (or type them)
3. Review cart on the left
4. Choose payment method:
   - **Cash** - Enter amount received
   - **M-Pesa** - Enter phone number
   - **Split** - Enter both amounts
5. Process payment
6. Print/save receipt

### Check Inventory Status
1. Go to **Reports**
2. Select **Inventory Report**
3. See stock levels and values
4. Identify low-stock items

### View Sales by Date
1. Go to **Reports**
2. Select **Sales Report**
3. See daily revenue
4. Print for records

### Manage User Roles
1. Go to **Admin** (Admin users only)
2. Create custom roles with specific permissions
3. Assign roles to users
4. Users get access based on their role

## 🆘 Troubleshooting

### "Login Failed"
- Check username is correct
- Verify password (case-sensitive)
- Ensure Caps Lock is off
- Try clearing browser cookies

### "Can't add item"
- Barcode must be unique
- All required fields must be filled
- Check item name is entered

### "Payment stuck"
- Internet connection might be down
- Try manual confirmation
- Check M-Pesa number format (+254 or 0...)

### "Can't see data"
- Refresh browser (Ctrl+F5)
- Check permissions with admin
- Ensure items were added to database
